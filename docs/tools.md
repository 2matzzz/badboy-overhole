# 工具チェックリスト

手持ちを確認して「持ってる」にチェック。なければ「買う」にチェックしてメイン発注に含める。リンクは定番品の例なので、同等品なら何でもよい。**数量はどれも1(セット品は1セット)でよい。**

補足: 車軸の玉当たり調整では「玉押しをハブスパナで押さえたまま外側のナットを別の工具で締める」という2本同時使いをするが、ハブスパナ3本セット+手持ちのモンキーレンチで足りる。
