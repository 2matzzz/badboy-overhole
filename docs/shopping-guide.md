# 購入ガイド(どこで買うと安いか)

2026-07-12 調査。価格はすべて検索結果で確認できた時点のもの(スニペットベース)なので、**注文前に商品ページで現在価格・在庫を必ず確認**すること。方針は「価格差が小さければデファクト定番メーカー(シマノ純正、HOZAN、パナレーサー、Velo等)の長く使えるものを選ぶ」。

## 調査で判明した重要事項

1. **FD-M191(前の変速機)は生産終了** — 在庫品がちゃりんこ王国に990円。在庫がなければ現行の **FD-TY710(約1,450円)** に切り替える(トップスイング・デュアルプル・バンド34.9mm+アダプター付きなので問題なく付く。見た目の形が今と少し変わるだけ)
2. **Jagwire DCA065(パッド)は国内流通がほぼない** — 代わりに **SRAM(AVID)純正 BB5用パッド(約2,829円/セット)** か **BBB BBS-43(定価2,750円)** を使う。シマノ・TEKTRO製パッドはBB5に非互換なので買わないこと
3. **SM-RT56(ローター)はレジンパッド専用** — 上記パッドはどちらもオーガニック(レジン系)なので問題なし
4. チェーンの実売は約3,000円(当初見積1,500円より高い)。カセットはBe.BIKEが約1,600円と突出して安い(カートで11-32Tを選択した時の価格を要確認)

### 節約オプション(約−6,000円 → 約45,000円)

- チェーンカッターを BIKE HAND YC-336(−3,100円)
- ワイヤーカッターを King TTC WC-150(−1,600円)
- パッドを BBB BBS-43 ×2(−100〜200円)+ローターをモノタロウ(送料圧縮)
- 便数を減らす(あさひ集約)と単価は少し上がるが送料と手間が減る
