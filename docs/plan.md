# 進め方の計画(イテレーション方式)

## 方針

- **小さく始める**: 一括で全バラしせず、サブシステム単位のイテレーションで進める。1回のイテレーションは半日〜1日で完結する規模にする。
- **毎回、乗れる状態で終わる**: 各イテレーションの最後は必ず組み上がって走れる状態に戻す。試走がそのまま動作確認になり、問題の切り分けも「今回触った箇所」に限定できる。
- **同じ箇所は二度開けない**: 依存関係のあるパーツ(ローターとパッド、チェーンとカセット、ワイヤーと変速機)は必ず同じ回でまとめて交換し、調整は1回で済ませる。
- **診断が先、分解は後**: 工具なしでできる点検をイテレーション0で全部やり、回転系(BB・ハブ・ヘッドセット)を開ける必要があるかを先に判断する。症状のない箇所はむやみに開けない。
- **工具は使う回に買い足す**: 初期投資を抑え、そのイテレーションで確実に使う工具だけ買う。

## 順番の理由

1. **タイヤが最初**: 一番簡単でリスクが低く、ホイール脱着・チューブ交換という今後ずっと使う基本スキルが身につく。失敗してもやり直しが容易。
2. **ブレーキが駆動系より先**: 安全に関わる箇所を先に確実にする。ローターとパッドは片方だけ新品にすると当たりが出ないので必ず同時交換し、その場で当たり出し(ベッディング)まで行う。
3. **リア駆動系を1回にまとめる**: チェーンとカセットは一緒に摩耗しているので同時交換が原則。RD とリアシフトワイヤーも同じ回に替えれば、変速調整(リミット・テンション・B テンション)は1回で済む。チェーン長の決定はカセット装着後に行う。
4. **フロントは別イテレーション**: FD は引き回しの現物確認(イテレーション0)を経てからでないと型番が確定しない。またリア変速が先に決まっていると FD 調整(チェーンライン基準)がやりやすい。シフターの要否判断(#13)はワイヤー交換後の動きを見てから。
5. **回転系は最後・症状ベース**: BB・ハブ・ヘッドセットは工具が重く失敗リスクも高い。イテレーション0の診断で症状があった箇所だけ、1回に1箇所ずつ開ける。リアハブ整備に必要なロックリング工具はイテレーション3で購入済みになっている。

## 再分解を避けるための依存関係メモ

- **ローター ⇔ パッド**: 必ず同時交換。新ローター+旧パッドは効かない・鳴く。
- **チェーン ⇔ カセット**: 必ず同時交換。伸びたチェーンで使ったカセットに新チェーンは歯飛びする。
- **ワイヤー ⇔ 変速機/ブレーキ本体**: 本体を替える回にワイヤーも新品にする。調整は1イテレーションにつき1回だけ。
- **BB → FD**: BB を交換するとチェーンラインが微妙に変わり FD の再調整が要ることがある。イテレーション0の診断で BB のゴリ感が明確なら、イテレーション5(BB)をイテレーション4(FD 調整)より先に繰り上げる。
- **ホイール脱着はコストゼロ扱い**: クイックリリースなので何度外しても「再分解」には数えない。タイヤ交換後にハブを開けることになっても手戻りではない。

## 発注バッチ戦略

送料と手戻りのバランスで、確定分は2回に分けて発注する。

- **バッチA(イテレーション0の直後)**: タイヤ・チューブ・リムテープ(#9〜11)、ブレーキ系(#5, #6, #8)、ケミカル(#16〜18)、タイヤレバー・T25・ワイヤーカッター
  → イテレーション1〜2をカバー。カセット刻印・リムテープ幅・タイヤ方針が確定してから発注する。
- **バッチB(イテレーション2完了ごろ)**: 駆動系(#1〜3, #7)、FD(#4、引き回し確認済みが条件)、チェーンカッター等の駆動系工具
  → イテレーション3〜4をカバー。
- **追加発注(都度)**: 回転系(#12〜15)と対応工具は、イテレーション0の診断結果と、開けた時の実測(BB 軸長、ハブ玉サイズ)が出てから。

## イテレーション0でやる診断(工具なし)

分解せずにできる点検で、イテレーション5の要否と順番を決める。

- **BB**: チェーンをインナーに落として(または外して)クランクを手で回し、ゴリ感・ガタ・異音を確認。クランクを左右に揺すってガタを見る。
- **ヘッドセット**: 前ブレーキを握って車体を前後に揺すりガタを確認。前輪を持ち上げてハンドルを切り、引っかかり・ゴリ感を確認。
- **ハブ前後**: ホイールを浮かせて空転させ、異音・ゴリ感を確認。リムを横に揺すってガタを確認。
- 結果は [inspection-notes.md](inspection-notes.md) に記録する。
