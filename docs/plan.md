# 進め方の計画

## ゴール

自転車を一度すみずみまでバラバラにして、

- **消耗している部品は全部交換する**(チェーン、歯車、タイヤ、ブレーキ関係、ワイヤー類)
- **錆びている部品は、錆を落として再利用するか、安い部品なら新品に交換する**
- **回転部(車軸・ペダル軸・ハンドル軸)は全部開けて、洗浄してグリスを入れ直す**

という流れで、新品同様の状態に組み直す。急いで乗れる状態に戻す必要はないので、じっくり進める。

## 進め方の原則

1. **同じ箇所は二度バラさない**: 一度開けた箇所は、その場で洗浄・点検・(必要なら)部品交換まで済ませてから閉じる。
2. **バラす前に必ず写真を撮る**: ワイヤーの通り道、部品の向き、ワッシャーの順番。組むときの答えは全部「バラす前の状態」にある。
3. **外したネジ・小物は箇所ごとに袋分けする**: 「車輪」「ブレーキ」など袋に書いておく。
4. **1ステップ=1回の作業日**: 半日〜1日で区切りがつく単位にしてある。次の作業日まで自転車は分解されたままで構わない(室内か雨の当たらない場所に置く)。
5. **迷ったら手を止めて記録する**: 無理に外そうとして壊すのが一番の手戻り。固くて外れない・向きがわからない時は写真を撮ってその日は終えてよい。

## この順番にする理由

- **ステップ1(車輪)が最初**: 車輪はフレームから独立して作業できるので、練習台として最適。タイヤ交換とベアリングの玉当たり調整という基本を、失敗してもやり直せる部品で覚えられる。
- **ステップ2〜4は「外して洗う」だけに集中**: 組み立てや調整を混ぜない。外した部品はその場で洗浄し、交換する部品(チェーンなど)は処分、再利用する部品は袋に入れて保管する。
- **開けたついでに全部診る**: ハブ・ボトムブラケット・ヘッドセットは開けたときにベアリングの状態を確認して、その場で「再利用(グリスアップ)か交換か」を判定する。交換が必要ならその場で追加発注し、届くまでの間に別ステップを進める。
- **組み立て(ステップ5)は一気にやらない**: フレームの中心(ボトムブラケット・クランク)→ ハンドル → 車輪 → 変速機 → ワイヤー → チェーンの順で、下から積み上げる。調整はステップ6でまとめてやる。

## 錆と消耗品の扱い方

外した部品は1つずつ「交換 / 錆取りして再利用 / そのまま再利用」に仕分ける。迷ったら次の基準で:

- **最初から交換と決めている消耗品**(チェーン、カセット、タイヤ、チューブ、リムテープ、ブレーキパッド、ローター、ワイヤー全部)は、状態を見ずに新品へ。旧品は処分。
- **ネジ・ボルト・ワッシャー類**: 錆びていたら基本は新品に交換(1本数十円〜)。ホームセンターで同じ太さ・長さのステンレス品を買えばよい。外した現物を持って行くと間違えない。
- **フレーム・クランクなど大物**: 交換すると高いので錆取りで再利用。表面の錆はサビ取り剤+真鍮ブラシで落とし、落とした後は油分(グリスやワックス)で保護する。
- **ベアリング(鋼球)**: 開けてみて、球や受け皿の表面に点状の凹み(虫食い)や錆があれば交換。球だけなら数百円。受け皿側が深くえぐれている場合はユニットごと交換([parts-list.md](parts-list.md) の #12〜15)。
- **判定に迷った部品**: 写真を撮って [inspection-notes.md](inspection-notes.md) に記録し、いったん「保留」の袋へ。組み立てまでに決めればよい。

## 二度手間を防ぐための組み合わせルール

- **ローターとブレーキパッドは同時に新品にする**: 片方だけ新しいと、うまく効かない・音が鳴る原因になる。
- **チェーンとカセットは同時に新品にする**: 伸びたチェーンと使い込んだ歯車は一緒に摩耗しているので、片方だけ替えると歯飛びする。
- **ワイヤーは変速機・ブレーキを組むときに新品を張る**: 古いワイヤーを組んでから替えると、調整をもう一度やり直すことになる。
- **ボトムブラケットの交換判定はフロント変速機の調整より前に済ませる**: ペダル軸が変わるとチェーンの位置が数ミリ変わり、前の変速機の調整がずれるため。この計画では自然にその順番になっている。
