## ステップ1: 車輪まわり(外して、開けて、綺麗にして、車輪だけ完成させる)

車輪は自転車から外して単体で作業できるので、最初の練習台にちょうどいい。

- [ ] 前後の車輪を自転車から外す(レバー式の留め具=クイックリリースを緩めるだけ)
- [ ] クイックリリースを分解して錆取り・グリスアップ → レバーの動きで再利用/交換を判定(錆確認済み)
- [ ] タイヤ・チューブ・リムテープを外して処分する(**外したリムテープの幅を測って #11 を注文** — 届くまで車輪の組み立ては待つ)
- [ ] ブレーキの円盤(ローター)を外す(星形ネジ6本、T25レンチ)→ 処分
- [ ] 車輪の金属部分(リム)とスポークを洗浄。錆びたスポークやニップル(スポークの根元の留め具)がないか点検 → あれば記録
- [ ] **車軸(ハブ)を開ける**: 薄いスパナ(ハブスパナ)でナットを緩め、中の鋼球を取り出す。左右の球の数を数えて記録する
- [ ] 球と受け皿の状態を確認 → 点状の凹みや錆があれば球を交換(#15)、綺麗ならそのまま
- [ ] 車軸の中を古いグリスごと拭き取り、新しいグリスをたっぷり入れて球を戻す
- [ ] 玉当たり調整: ガタつかず、かつ軽く回るところでナットを固定する(何度かやり直してよい)
- [ ] 新しいリムテープを貼る(空気を入れる穴=バルブ穴の位置を合わせる)
- [ ] 新しいタイヤとチューブを付ける(チューブがタイヤと車輪の間に噛み込んでいないか全周確認してから空気を入れる)
- [ ] 新しいローターを付ける(ネジ6本を対角線の順で少しずつ締める)
- [ ] 完成した車輪2本は綺麗な場所に保管

## ステップ2: 駆動系を外して洗う(チェーン・歯車・変速機・ペダル軸)

- [ ] 外す前に、変速機まわりとチェーンの通り道を写真に撮る
- [ ] チェーンの長さ(コマ数)を数えて記録 → チェーンカッターで切って処分
- [ ] 後輪から歯車の束(カセット)を外す(専用工具2点)→ 処分。車軸側の筒(フリーハブ)が指でスムーズに回るか確認して記録
- [ ] 後ろの変速機(リアディレイラー)を外す → 処分(新品に交換)
- [ ] 前の変速機(フロントディレイラー)を外す → 処分(新品に交換)
- [ ] ペダルとクランク(ペダルが付いている腕)を外す(クランク抜き工具)
- [ ] **ペダル軸(ボトムブラケット)を外す**(BB工具)。軸の長さを測って記録
- [ ] 手で回してゴリゴリした感触がないか確認 → ゴリ感や錆があれば新品に交換(#12)、スムーズなら再利用
- [ ] クランクとチェーンリング(ペダル側の歯車)を洗浄。歯が尖って波形に減っていないか確認 → ひどければ追加交換を検討
- [ ] ペダルを分解せず外側だけ洗浄(ゴリゴリするなら交換候補として記録)
- [ ] 外したネジ類で錆びているものを仕分けて、ホームセンターで買い直すリストを作る

## ステップ3: ブレーキとワイヤーを外して洗う

- [ ] 外す前にワイヤーの通り道を前後とも写真に撮る(アウターの長さも後で切る時の見本になるので保管)
- [ ] 変速用ワイヤー(インナー・アウターとも)を全部外す → 処分
- [ ] ブレーキ用ワイヤーも全部外す → 処分
- [ ] ブレーキ本体(キャリパー)から古いパッドを外す → 処分
- [ ] キャリパー本体を外して洗浄(可動部の動きを確認。固着していれば記録)
- [ ] ハンドルまわりのレバー類(ブレーキレバー・変速レバー)の動きを確認 → 変速レバーが渋ければシフター交換(#13)を判断
- [ ] フレームのワイヤー受け(アウター受け・ガイド)の錆と汚れを掃除

## ステップ4: ハンドルまわりの分解と、フレーム丸洗い

- [ ] ハンドルとステム(ハンドルの支柱)を外す(六角レンチ)。外す前に高さと角度がわかる写真を撮る。てっぺんのトップキャップのボルトは錆確認済み — なめないよう六角レンチを奥まで差してゆっくり回す(外れたら処分、新品 #21 に交換)
- [ ] 古いグリップを外して処分(固着していたらカッターで切る)。**バーの金属部分に腐食・深い傷がないか確認** → あれば写真を撮ってバー交換を判定
- [ ] **前フォークを抜いてハンドル軸のベアリング(ヘッドセット)を開ける**。部品の重なり順を1つずつ写真に撮りながら外す
- [ ] ベアリングの状態を確認 → 錆・虫食いがあれば交換(#14)、綺麗なら洗浄してグリスを入れ直す
- [ ] サドルとシートポスト(サドルの支柱)を抜く。差し込み部の錆を落としてグリスを塗る(旧サドルは処分、外す前に角度・前後位置の写真を撮る)
- [ ] 何も付いていなくなったフレームとフォークを丸洗いする
- [ ] フレームの錆をサビ取り剤+真鍮ブラシで落とし、傷やヒビがないか全体を点検 → 気になる箇所は写真を撮って記録
- [ ] ネジ穴(ボトルケージ台座など)の錆を落としてグリスを薄く塗る
- [ ] **追加発注**: ここまでの判定で交換になった部品(#12〜15、錆びたネジ類、その他)をまとめて注文する

## ステップ5: 組み立て(部品が全部揃ってから、下から積み上げる)

- [ ] ペダル軸(ボトムブラケット)を取り付ける(ネジ部にグリス)
- [ ] クランクとペダルを取り付ける
- [ ] ヘッドセットを組んでフォーク・ステム・ハンドルを戻す(ガタが出ないよう締め順に注意: 上蓋のネジで当たりを出してからステムの横ネジを締める)
- [ ] シートポストを戻し、**新しいサドル**を取り付ける(高さは元の印、前後位置と角度は旧サドルの写真を参考に)
- [ ] **新しいグリップ**を取り付ける(ブレーキ・変速レバーの角度を合わせてから)
- [ ] 後輪に新しい歯車の束(カセット)を取り付ける(専用工具で規定の強さに締める)
- [ ] 前後の車輪を取り付ける
- [ ] 前後の変速機を取り付ける(前の変速機は、羽根と歯車の隙間1〜3mm・平行が目安)
- [ ] ブレーキ本体と新しいパッドを取り付ける
- [ ] 新しいワイヤーを張る(ブレーキ2本・変速2本。アウターは古いものと同じ長さに切る)
- [ ] 新しいチェーンを付ける(長さは記録しておいた旧チェーンのコマ数に合わせる)

## ステップ6: 変速とブレーキの調整

- [ ] ブレーキ調整: パッドと円盤の隙間を左右均等にする(BB5は固定側パッドの位置を先に決めるのがコツ)→ レバーの引きしろを好みに合わせる
- [ ] 後ろの変速調整: 動く範囲の上限・下限のネジ → ワイヤーの張り → 全段スムーズに変わるまで微調整
- [ ] 前の変速調整: 同じく下限 → ワイヤーの張り → 上限の順
- [ ] 全部のギアの組み合わせでチェーンが擦れないか確認
- [ ] 各部のネジの締め忘れがないか一周確認(ハンドル・ステム・サドル・車輪・クランク)

## ステップ7: 試走と仕上げ

- [ ] ブレーキの当たり出し: 安全な場所で、中くらいのスピードからしっかり止まるのを20〜30回繰り返す(新品パッドと円盤はこれをやると効きが出る)
- [ ] 試走して全ギアの変速・ブレーキ・異音をチェック
- [ ] 数日〜1週間後、ワイヤーの初期伸びを取る(ブレーキ・変速とも再調整)
- [ ] チェーンに油をさして余分を拭き取る
- [ ] 完成写真を撮る。かかった費用の合計をまとめて README に記録
