# 作業タスク

進め方の考え方と順番の理由は [plan.md](plan.md) を参照。各イテレーションは「乗れる状態に戻して試走」で完了とする。判断・計測の結果は [inspection-notes.md](inspection-notes.md) に、発注状況は [parts-list.md](parts-list.md) に反映する。

## イテレーション0: 診断・現物確認(分解なし)

- [ ] 全体・各部の写真を撮る(ワイヤー引き回し、パーツ位置の記録)
- [ ] FD の引き回し確認(トップスイング/ダウンスイング、トッププル/ボトムプル、バンド径)
- [ ] カセットの歯数刻印を確認(11-32T 想定)
- [ ] リムテープ幅を確認
- [ ] タイヤ幅の方針決定(28C / 32C、マラソン / コジャック)
- [ ] BB 診断: クランク手回しでゴリ感・ガタ・異音チェック
- [ ] ヘッドセット診断: 前ブレーキ握って前後揺すり+ハンドル切って引っかかりチェック
- [ ] ハブ診断: 前後ホイール空転+横揺すりでゴリ感・ガタチェック
- [ ] 手持ち工具の棚卸し
- [ ] 診断結果を inspection-notes.md に記録し、イテレーション5 の対象箇所を確定
- [ ] **バッチA発注**: #5, #6, #8, #9, #10, #11, #16〜18 + タイヤレバー・トルクスT25・ワイヤーカッター

## イテレーション1: タイヤ・チューブ・リムテープ

- [ ] 前後ホイールを外す
- [ ] タイヤ・チューブ・リムテープを外す
- [ ] リム内側を清掃、ニップル穴のバリ・錆を確認
- [ ] 新リムテープを貼る(バルブ穴合わせ)
- [ ] 新タイヤ・チューブを装着(ビード落とし込み、チューブ噛み込み確認)
- [ ] 規定空気圧まで入れてビードの上がりを全周確認
- [ ] ホイールを戻して試走
- [ ] ふりかえり: 気づきを inspection-notes.md に追記

## イテレーション2: ブレーキ一式(ローター・パッド・ワイヤー)

- [ ] 交換前のキャリパー位置・ワイヤー引き回しを写真に記録
- [ ] 前後ローターを交換(T25、対角に規定トルクで締める)
- [ ] 前後パッドを交換(ローターに素手で触れない・油分厳禁)
- [ ] ブレーキワイヤー(インナー/アウター)を前後とも交換
- [ ] キャリパー調整(BB5 は固定側パッドの位置出し → 可動側クリアランス)
- [ ] レバー引きしろ調整
- [ ] 当たり出し(ベッディング): 中速からの制動を20〜30回繰り返す
- [ ] 試走(効き・引きずり・鳴きチェック)
- [ ] ふりかえり記録
- [ ] **バッチB発注**: #1, #2, #3, #7(+確認済みなら #4)+ チェーンカッター・ロックリング工具・スプロケ回し

## イテレーション3: リア駆動系(チェーン・カセット・RD・リアシフトワイヤー)

- [ ] 交換前の RD 取り付け・ワイヤー引き回し・チェーンのコマ数を記録
- [ ] チェーンを切って外す(コマ数を数えておく)
- [ ] カセットを外して新品に交換(ロックリング規定トルク)
- [ ] フリーハブボディの回転を指で確認(ついで診断)
- [ ] RD を交換
- [ ] リアシフトワイヤー(インナー/アウター)を交換
- [ ] チェーン装着(長さは旧チェーン基準+アウター×ロー+2コマで検算)
- [ ] RD 調整: H/L リミット → ワイヤーテンション → B テンション
- [ ] 全段変速チェック(スタンド上 → 試走)
- [ ] チェーンオイル塗布・拭き上げ
- [ ] ふりかえり記録

## イテレーション4: フロント変速(FD・フロントシフトワイヤー)

- [ ] FD を交換(バンド位置: 羽根とアウターチェーンリングの隙間 1〜3mm、羽根とリングが平行)
- [ ] フロントシフトワイヤー(インナー/アウター)を交換
- [ ] FD 調整: L リミット → ワイヤーテンション → H リミット
- [ ] 全組み合わせで変速チェック、チェーン擦れ確認(スタンド上 → 試走)
- [ ] シフターの動き確認 → 渋ければ #13(SL-M315)の発注を判断
- [ ] ふりかえり記録

## イテレーション5: 回転系(イテレーション0で症状があった箇所だけ・1回に1箇所)

### 5a. ハブ(該当する場合)

- [ ] ハブスパナのサイズを実測して購入
- [ ] 玉押しを開けて玉・玉受けの状態を確認 → inspection-notes.md に記録
- [ ] 虫食いなら玉交換(#15)、無事ならグリスアップ
- [ ] 玉当たり調整(ガタなし・ゴリなしの点を出す)
- [ ] 組み戻して試走

### 5b. ヘッドセット(該当する場合)

- [ ] フォークを抜いてベアリング状態を確認 → 記録
- [ ] 錆・虫食いなら交換(#14)、無事なら洗浄・グリスアップ
- [ ] 組み戻してガタ取り(ステム締結の順序に注意)、試走

### 5c. BB(該当する場合)

- [ ] コッタレスクランク抜き・BB工具を購入
- [ ] クランクを抜いて BB を外す、軸長・シェル幅を実測 → 記録
- [ ] ゴリ感あれば交換(#12、軸長を合わせて発注)、無事なら清掃して戻す
- [ ] クランク取り付け(規定トルク)、FD の変速を再確認、試走

## イテレーション6: 総仕上げ

- [ ] ワイヤー初期伸び取り(ブレーキ・変速とも再調整)
- [ ] 各部増し締め・トルク確認(ステム、ハンドル、シートポスト、ホイール、クランク)
- [ ] シートポストを抜いてグリスアップ
- [ ] フレーム全体の清掃・ワックス
- [ ] 仕上がり試走(変速全段・ブレーキ・異音の最終チェック)
- [ ] 完成写真を撮って記録、総費用をまとめる
