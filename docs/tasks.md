# 作業タスク

上から順に進める。「開けて判断」フェーズの結果は [inspection-notes.md](inspection-notes.md) に記録し、追加発注は [parts-list.md](parts-list.md) の要否欄を更新する。

## フェーズ0: 発注前の現物確認

- [ ] FD の引き回し確認(トップスイング/ダウンスイング、トッププル/ボトムプル)→ inspection-notes.md に記録
- [ ] カセットの歯数刻印を確認(11-32T想定)
- [ ] リムテープ幅を確認
- [ ] タイヤ幅の方針決定(28C / 32C、マラソン / コジャック)
- [ ] 手持ち工具の棚卸し

## フェーズ1: 発注(確定分)

- [ ] parts-list.md の確定発注 #1〜11 を発注
- [ ] ケミカル #16〜18 を発注
- [ ] 不足工具を発注

## フェーズ2: 分解

- [ ] 分解前の全体・各部写真を撮る(ワイヤー引き回し、パーツ位置の記録)
- [ ] ホイール前後を外す
- [ ] タイヤ・チューブ・リムテープを外す
- [ ] ローター前後を外す
- [ ] チェーンを切って外す
- [ ] カセットを外す
- [ ] RD・FD を外す
- [ ] シフト・ブレーキワイヤー(インナー/アウター)を撤去
- [ ] ブレーキキャリパーのパッドを外す
- [ ] クランクを抜く
- [ ] BB を外す
- [ ] フォークを抜いてヘッドセットを分解
- [ ] ハブ前後を開ける(玉押し・ベアリング点検)

## フェーズ3: 開けて判断 → 追加発注

- [ ] BB の回転チェック(ゴリ感あれば交換。軸長を実測して記録)
- [ ] ヘッドセットのベアリング点検(錆 → 交換 / 無事 → グリスアップ)
- [ ] ハブのベアリング・玉受け点検(虫食い → 玉交換)
- [ ] シフターの動作確認(ワイヤー交換後に再判定でも可)
- [ ] 追加発注の要否を parts-list.md に反映して発注

## フェーズ4: 洗浄・グリスアップ

- [ ] フレーム・フォークの洗浄
- [ ] クランク・チェーンリングの洗浄
- [ ] ブレーキキャリパーの清掃
- [ ] ハブの洗浄・グリスアップ・玉当たり調整
- [ ] ヘッドセットの洗浄・グリスアップ
- [ ] 各ネジ穴・シートポストのグリスアップ

## フェーズ5: 組付け

- [ ] BB 取り付け(交換 or 再利用)
- [ ] クランク取り付け
- [ ] ヘッドセット・フォーク組付け
- [ ] リムテープ・タイヤ・チューブ装着
- [ ] ローター取り付け(6ボルト、規定トルク)
- [ ] ホイール装着
- [ ] カセット取り付け(ロックリング締め付け)
- [ ] RD・FD 取り付け
- [ ] ブレーキパッド装着
- [ ] ブレーキワイヤー張り
- [ ] シフトワイヤー張り
- [ ] チェーン装着(リンク数は旧チェーン基準+RD キャパ確認)

## フェーズ6: 調整

- [ ] ブレーキキャリパー位置・パッドクリアランス調整(BB5 は固定側パッドから)
- [ ] RD 調整(H/L リミット、ワイヤーテンション、B テンション)
- [ ] FD 調整(H/L リミット、羽根の高さ・角度)
- [ ] 各部増し締め・トルク確認
- [ ] ホイール振れ確認

## フェーズ7: 試走・仕上げ

- [ ] 近所で試走(変速全段、ブレーキ効き、異音チェック)
- [ ] 初期伸び取り(ワイヤー再調整)
- [ ] チェーンオイル塗布・拭き上げ
- [ ] 完成写真を撮って記録
