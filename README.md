# Bad Boy オーバーホール

Cannondale Bad Boy のオーバーホール計画・進行管理用リポジトリ。

一度すみずみまでバラバラにして、消耗品は全部交換、錆は落とすか交換、回転部は全部グリスを入れ直して、新品同様に組み直す。急いで乗れる状態に戻す必要はないので、1ステップずつじっくり進める。

## ドキュメント

| ファイル | 内容 |
|---|---|
| [docs/plan.md](docs/plan.md) | 進め方の計画: 用語集、ステップ一覧と順番の理由、錆・消耗品の扱い方、工具の買い物リスト |
| [docs/tasks.md](docs/tasks.md) | ステップ0〜7の作業チェックリスト |
| [docs/parts-list.md](docs/parts-list.md) | 買うものリスト(メイン発注 / 追加発注 / ケミカル)と発注・到着チェック |
| [docs/inspection-notes.md](docs/inspection-notes.md) | 現物確認・計測・交換判定の記録 |

## ステップ概要

| ステップ | やること | 状態 |
|---|---|---|
| 0 | 現物チェックと発注(分解しない) | 未着手 |
| 1 | 車輪まわり: タイヤ・チューブ交換、車軸の分解清掃、ブレーキ円盤交換 | 未着手 |
| 2 | 駆動系を外して洗う: チェーン・歯車・変速機・ペダル軸 | 未着手 |
| 3 | ブレーキとワイヤーを外して洗う | 未着手 |
| 4 | ハンドルまわりの分解と、フレーム丸洗い → 追加発注 | 未着手 |
| 5 | 組み立て(下から積み上げ) | 未着手 |
| 6 | 変速とブレーキの調整 | 未着手 |
| 7 | 試走と仕上げ | 未着手 |

## 予算感

- パーツ(確定分): **約25,000〜28,000円**
- 追加交換が全部発生した場合: **35,000円前後**
- 工具: **約9,500円**(チェーンカッター、車軸用の薄いスパナ、ペダル軸の工具など)

作業の結果や気づきはチェックとコミットで記録していく。
