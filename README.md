# Bad Boy オーバーホール

Cannondale Bad Boy のフルオーバーホール計画・進行管理用リポジトリ。

## ドキュメント

| ファイル | 内容 |
|---|---|
| [docs/parts-list.md](docs/parts-list.md) | 発注パーツ一覧(確定発注 / 開けてから判断 / ケミカル)と発注・到着チェック |
| [docs/tasks.md](docs/tasks.md) | 作業タスクのチェックリスト(分解 → 判断 → 洗浄 → 組付け → 調整) |
| [docs/inspection-notes.md](docs/inspection-notes.md) | 発注前・分解時に現物で確認する事項と、その記録 |

## 予算感

- 確定発注分: **約 25,000〜28,000 円**
- 追加発注が全部発生した場合: **35,000 円前後**
- 工具類(チェーンカッター、スプロケ外し、BB工具など)未所持なら別途 **約 8,000 円**

## 進め方

1. `docs/inspection-notes.md` の「発注前に確認」を済ませる(特に FD の引き回し)
2. `docs/parts-list.md` の確定分を発注
3. `docs/tasks.md` に沿って分解 → 開けて判断ポイントで追加発注を確定
4. 洗浄・組付け・調整 → 試走

各作業の結果や気づきはコミットで記録していく。
