# Bad Boy オーバーホール

Cannondale Bad Boy のオーバーホール計画・進行管理用リポジトリ。

一度すみずみまでバラバラにして、消耗品は全部交換、錆は落とすか交換、回転部は全部グリスを入れ直して、新品同様に組み直す。急いで乗れる状態に戻す必要はないので、1ステップずつじっくり進める。

## ドキュメント

| ファイル | 内容 |

| [docs/tasks.md](docs/tasks.md) | ステップ0〜7の作業チェックリスト |

| [docs/tools.md](docs/tools.md) | 工具チェックリスト(定番品へのリンク付き、持ってる/買うの棚卸し) |

## ステップ概要

| ステップ | やること | 状態 |
|---|---|---|
| 0 | 現物チェックと発注(分解しない) | 確認完了・発注待ち |
| 1 | 車輪まわり: タイヤ・チューブ交換、車軸の分解清掃、ブレーキ円盤交換 | 未着手 |
| 2 | 駆動系を外して洗う: チェーン・歯車・変速機・ペダル軸 | 未着手 |
| 3 | ブレーキとワイヤーを外して洗う | 未着手 |
| 4 | ハンドルまわりの分解と、フレーム丸洗い → 追加発注 | 未着手 |
| 5 | 組み立て(下から積み上げ) | 未着手 |
| 6 | 変速とブレーキの調整 | 未着手 |
| 7 | 試走と仕上げ | 未着手 |

## 予算感(2026-07-12 確定版)

- **メイン発注: 実売ベースで約50,000〜52,000円(送料込み)** — 品目別の最安店とまとめ買いプランは [docs/shopping-guide.md](docs/shopping-guide.md)
  - 節約構成(工具の一部を安価定番品に等)なら**約45,000円**
- 後日確定分: リムテープ 約800円(ステップ1で幅を実測してから)
- 追加発注(開けて交換になった場合のみ): 全部発生しても **+10,000円程度**(BB・ヘッドセット・ハブ球・シフター・クイックリリース・錆ネジ)

作業の結果や気づきはチェックとコミットで記録していく。
