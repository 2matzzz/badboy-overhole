# Bad Boy オーバーホール

Cannondale Bad Boy のオーバーホール計画・進行管理用リポジトリ。

一括で全バラしせず、**サブシステム単位のイテレーション**で進める。各イテレーションは「乗れる状態に戻して試走」で完了。詳しい方針と順番の理由は [docs/plan.md](docs/plan.md) を参照。

## ドキュメント

| ファイル | 内容 |
|---|---|
| [docs/plan.md](docs/plan.md) | 進め方の計画: イテレーション一覧、順番の理由、依存関係、発注バッチ戦略 |
| [docs/tasks.md](docs/tasks.md) | イテレーション0〜6の作業チェックリスト |
| [docs/parts-list.md](docs/parts-list.md) | 発注パーツ一覧(確定発注 / 開けてから判断 / ケミカル)と発注・到着チェック |
| [docs/inspection-notes.md](docs/inspection-notes.md) | 現物確認・診断・計測の記録 |

## イテレーション概要

| # | テーマ | 状態 |
|---|---|---|
| 0 | 診断・現物確認(分解なし)→ バッチA発注 | 未着手 |
| 1 | タイヤ・チューブ・リムテープ | 未着手 |
| 2 | ブレーキ一式(ローター・パッド・ワイヤー)→ バッチB発注 | 未着手 |
| 3 | リア駆動系(チェーン・カセット・RD・ワイヤー) | 未着手 |
| 4 | フロント変速(FD・ワイヤー) | 未着手 |
| 5 | 回転系(ハブ / ヘッドセット / BB、症状があるものだけ) | 未着手 |
| 6 | 総仕上げ(初期伸び取り・増し締め・清掃) | 未着手 |

## 予算感

- 確定発注分: **約 25,000〜28,000 円**(バッチA+Bに分割)
- 追加発注が全部発生した場合: **35,000 円前後**
- 工具はイテレーションごとに買い足し(合計目安 **約 8,000 円**、回転系を開けない場合はもっと少ない)

各作業の結果や気づきはチェックとコミットで記録していく。
